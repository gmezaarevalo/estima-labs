## 🚀 Despliegue en GitHub Pages

Para publicar este proyecto bajo tu dominio `https://<tu-usuario>.github.io/<tu-repo>`:

1. Ve a **[GitHub > New Repository](https://github.com/new)** y crea un repositorio público (ej. `estima-labs`).
2. Sube los archivos `index.html` y `README.md`.
3. Entra a **Settings > Pages**, en *Build and deployment* selecciona la rama `main` (directorio `/root`) y guarda.
4. En 30 segundos tu sitio estará disponible globalmente en GitHub Pages.
